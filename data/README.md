# Reference `.mat` data

## Files included in this repository

The following reference solutions were generated by the thesis author and
are redistributed here under the repository's CC BY-NC 4.0 license:

| File                   | Equation and configuration                   |
|------------------------|----------------------------------------------|
| `NLS_N1.mat`           | NLS, $N=1$ fundamental soliton               |
| `NLS_N2.mat`           | NLS, $N=2$ Satsuma–Yajima bound state        |
| `Bright_soliton.mat`   | Hirota (Zhou & Yan), $N=1$ bright soliton    |

## Files available on request by email

The three files below are **not redistributed in this repository**. They
include MATLAB-generated solutions shared with the author by Dr. Leonid Serkin
for the two-soliton configurations.

| File                               | Equation and configuration                    |
|------------------------------------|-----------------------------------------------|
| `NLS_2soliton_interaction.mat`     | NLS, $N=2$ two-soliton collision              |
| `hirota_N_2.mat`                   | Hirota (Serkin), $N=2$ bound state (breather) |
| `N_2_hirota_inter.mat`             | Hirota (Serkin), $N=2$ two-soliton collision  |

### How to request

Send a short email to:
